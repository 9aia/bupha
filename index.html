Getting Started
Tamias bundles

Push → status in seconds

HMAC-verified webhooks, delivery dedup, honest pending/success/cancelled statuses — no YAML, no queue wait

first run

Your box, your cache

no runner minutes; build caches on your own disk or your S3/R2/minio via sccache

cache backends

Two queue modes

latest-wins for CI gates, bounded FIFO for releases — per repo; superseded shas never silently drop

queue semantics

Detached worktrees

every run is an isolated git worktree of the pushed sha — never a shared, dirty checkout

Ports, not frameworks

sources (github-webhook push/PR, sturn-wal) → queue → runner (dagger | shell | ssh | gha) + status — swap via config or a new adapter crate

architecture

Secrets stay secret

env var → cuora (`cuora://bupha/`, canonical) → `~/.config/bupha/env` (dev-mode / no-cuora fallback; the OS-keyring leg was dropped post-T-077); config holds names, never values; tokens never reach argv
