Config — bupha.toml ​

Top level ​

fieldtyperequirednotes
reposVec<RepoEntry>requiredWatched repos — one pending slot each, one global worker. TOML-conventional singular; repos kept as alias for existing configs.
tunnelTunnelCfgoptionalHow the listener is exposed publicly (cloudflared, direct, none).
cacheCacheCfgoptionalArtifact cache backend ([cache]); runner.sccache_conf is accepted for older configs — [cache] wins.
worktreeWorktreeCfgoptionalWhere detached git worktrees for runs are created.

[[repo]] ​

fieldtyperequirednotes
namestringrequiredrepository.full_name in the webhook payload ("owner/name") — also the status target repo.
dirpathrequiredClone to fetch + create detached worktrees from.
branchstringoptionalThe ref to watch (e.g. "refs/heads/main").
status_repostringoptionalStatus repo override (defaults to name).
runnerRunnerCfgoptionalPer-repo runner override — a full [repo.runner] table replaces the global [runner] for this repo.
queue`"latest""all"`optional

[trigger] ​

fieldtyperequirednotes

secret_envstringoptionalEnv var holding the webhook secret.

[runner] ​

fieldtyperequirednotes
kindstringrequiredRunner kind: "dagger" | "shell" | "ssh" | impl crates.
token_envstringoptionalEnv var name holding the forge token (never the value).
cancel_runningbooloptionalKill an in-flight run when a newer push supersedes it. Invalid with queue = "all" (rejected at load).
extratoml::TablerequiredImpl-owned fields — the matched impl crate deserializes its own config struct from this; core knows none of them.

Constraints ​

  • queue = "all" rejects cancel_running = true at load — killing a run would silently drop a promised commit.
  • runner.kind and trigger.kind/status.kind resolve to impl crates; unknown kinds fail at bupha doctor/startup.
  • deny_unknown_fields: typos in field names fail the load.
