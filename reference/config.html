Config reference ​

bupha.toml. Secrets are never values here — only env-var names (secret_env, token_env, sccache_conf).

Top level ​

fieldtyperequirednotes
repoRepoCfgoptionalLegacy single-repo form; prefer [[repos]].
reposVec<RepoEntry>optionalWatched repos — one pending slot each, one global worker.
tunnelTunnelCfgoptional—
worktreeWorktreeCfgoptional—

Constraints ​

  • queue = "all" rejects cancel_running = true at load — killing a run would silently drop a promised commit.
  • runner.kind and trigger.kind/status.kind resolve to impl crates; unknown kinds fail at bupha doctor/startup.
  • deny_unknown_fields: typos in field names fail the load.
