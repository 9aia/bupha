# ADR-0005: bupha is the CI repo — un-deprecation, gha dialect, tamias driver

Status: **accepted** · Created: 2026-11-10 · Amends: org ADR-0080 (CI-absorption half), supersedes the 2026-10-31 deprecation

## Context

bupha was deprecated one day after PL-007/P-007 moved the org gate
to peregrin campaigns (`libraries/ci-gate`). Direction reversed: the
org wants a dedicated CI repo — forge-agnostic engine, GitHub first,
GitLab later — that also serves as a tamias content type.

## Decision

1. **bupha is un-deprecated and is the CI product repo.** Engine
   stays ports-and-adapters; no peregrin dependency — peregrin
   keeps generic orchestration, bupha owns turnkey repo CI.
2. **Runner port gains CI-dialect impls.** `runner.kind = "gha"`
   (`crates/bupha-gha`) executes `.github/workflows/*.yml` on.push
   natively: pure `plan.rs` core (parse/select/expand) + bash
   executor over the existing `RunHandle`. Supported subset is
   explicit; unsupported syntax hard-errors (crate README is the
   contract). `dagger`/`shell`/`ssh`/`container`/`http` remain
   sibling impls. `.gitlab-ci.yml` is a later sibling (T-047);
   `plan.rs` is dialect-agnostic by design.
3. **Forge stays ported**: `github` trigger+status today;
   `pull_request` events added (opened/synchronize/reopened,
   opt-in via `[[repo]] events`). `bupha-gitlab` is backlog
   (T-046).
4. **`tamias-driver-bupha` is a full content driver** (`type:
   bupha`): tamias lifecycle verbs (install/deploy/uninstall) +
   provider verbs (hooks/health/status/logs/config-schema) alongside
   the existing pavo view surface. `deploy` writes per-bundle
   `~/.config/bupha/bundles/<name>.toml` (config has no include
   mechanism — the unit's `--config` consumes it, same pattern as
   peregrin's per-bundle node configs).
5. **`libraries/` ships CI bundles as tamias packages**:
   `ci-gate` (org gate, migrating back from peregrin — fleet config
   generated by `bupha import <campaign.yaml>`, 189 repos verified)
   and `docs-deploy`.

## Consequences

- The org gate returns to bupha-native config; cutover is live-ops
  (shadow → webhook repoint → retire peregrin bundle), tracked as
  org T-002.
- Two queue/event models coexist (bupha + peregrin) — accepted:
  consumers differ (turnkey CI vs. general orchestration).
- `gha` fidelity is capped at the documented subset; widening it
  (setup-* actions, `if:`, parallel matrix, per-job statuses) is
  backlog T-048.
