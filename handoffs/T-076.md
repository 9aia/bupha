# Handoffs — T-076

## 2026-11-13 · human:Luis-Emidio
ROOT CAUSE FOUND + FIXED (live outage 2026-11-13): ci-ingress@0.3.4 dropped env_file from tamias.yaml services.campaign — the file carries PEREGRIN_* process knobs (PEREGRIN_CUORA_TRANSPORT=serve, PEREGRIN_PUSH_BACKEND, PEREGRIN_TOKEN, PEREGRIN_SEPIA, PEREGRIN_HOST), not secrets. Without it the generated peregrin-campaign.service lost EnvironmentFile → cuora transport fell back to CLI → ~185+ sequential 'cuora get' process spawns across 5 campaigns sharing one listener → route registration took 20min+ / effectively never; webhook probes 404'd. Fixed in 0.3.5 (env_file restored, knobs-vs-secrets comment) — deployed, routes register <60s. STILL OPEN: (a) listener-run failures remain silent — empty history, no node.failed surfaced, death invisible until probe/restart (the actual T-076 scope); (b) ~2min startup is serialized cuora-serve gets across all campaigns — batch get_many or parallel resolution would cut it; (c) 'tamias deploy regenerates unit' silently dropped operator env — deploy should warn when env_file disappears between versions.
