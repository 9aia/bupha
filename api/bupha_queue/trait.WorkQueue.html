Expand description

Shared pull queue — N producers (watchers) enqueue, M consumers (workers) claim with a lease. A dead worker’s leased job becomes claimable again when its lease expires; complete settles it.

Scan keys for a claimable job: not done, labels satisfied by worker_labels, lease won. Latest-policy keys prune entries superseded by the claimed/newest sha.

fn complete(&self, job: &Job, worker: &str) -> Result<()>

Settle a claimed job — marks done, removes the list entry, releases the lease. No-op if worker no longer holds it.
