Crate bupha_queue 

Source
Expand description

QueueStore port — durable queue persistence for the watcher. JSON-file impl in bupha-queue-json; SQLite/remote = new impls. WorkQueue port — the shared pull queue a fleet of bupha worker processes claims jobs from (per-key lists + leases).

Structs§

Job
A job pushed for the fleet — the sha to run plus the labels a claiming worker must carry.
KeyPolicy
A key a worker is willing to run — its queue policy decides claim order (newest-only for latest, FIFO for all).
MemWorkQueue
In-memory WorkQueue — same-process semantics for single-box use and tests. Claims can’t expire (no TTL), so a claimed entry leaves the list until completed.
PersistedQueue
One repo’s persisted slice: pending backlog + the sha that was running when the process stopped (re-queued at the front). Serializable per-repo queue snapshot — what a store writes.

Traits§

QueueStore
Queue persistence — load/save the full per-repo map.
WorkQueue
Shared pull queue — N producers (watchers) enqueue, M consumers (workers) claim with a lease. A dead worker’s leased job becomes claimable again when its lease expires; complete settles it.
