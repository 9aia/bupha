Redis adapter of QueueStore + TryClaim — the multi-worker store. Each repo’s queue is its own key (bupha:queue:{key}) so persist_key updates never clobber a peer watcher’s entries; try_claim is atomic via SET … NX PX with a fencing counter (INCR bupha:fence), and finished runs leave a bupha:done:{key}: {sha} marker so peers drop their redundant copies instead of re-running. Lease TTL 5 min; workers renew by re-claiming.
