Audit adapter (ADR-0002 §2) — appends every access decision and run outcome to <worktree.base>/audit.log as JSONL. Two shapes on one writer: AuditLog::entry for direct events (access deny, runner decisions) and AuditSink — a StatusSink decorator so status posts leave an audit line too.

Structs§

AuditLog
Append-only JSONL writer. One Mutex serializes lines between the listener thread (access decisions) and run workers (statuses).
AuditSink
StatusSink decorator — records post() as an audit entry under this repo, then delegates to the wrapped sink. sender isn’t in the post signature; status lines leave it empty (access-deny lines, written via AuditLog::entry directly, carry it).
