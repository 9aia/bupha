Expand description

Try to claim a sha for worker. Some(fence) = this worker owns the run; None = another worker holds it.

fn renew(&self, repo: &str, sha: &str, worker: &str) -> Result<bool>

Extend a held claim’s TTL. Long runs renew periodically so the lease doesn’t expire mid-build. false = the claim was lost (expired or stolen). Default: always-held (single-box stores).

Source

fn is_done(&self, repo: &str, sha: &str) -> Result<bool>

Has this sha already been run to completion by ANY worker? Peers drop their redundant queue entries on true — without it a sha a peer already ran would sit at the front of the queue until the lease expired, then re-run. Default: never (single box — no peer could have finished it).

Source

fn mark_done(&self, repo: &str, sha: &str) -> Result<()>

Mark a sha complete — peers drop their redundant entries. Default no-op (single box).
