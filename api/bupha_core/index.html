bupha-core — domain types, bupha.toml config, and the latest-wins queue every runner impl shares.

The queue is the batch semantic for fast-pushing repos: at most one run in flight plus one pending sha — newer pushes supersede the pending one (skipped shas should get a “superseded” status from the caller). N commits during a run = 1 follow-up run on the newest.
