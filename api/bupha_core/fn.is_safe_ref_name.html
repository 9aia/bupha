pub fn is_safe_ref_name(r: &str) -> bool
Expand description

A fetch ref (headRef) — a branch name or full ref like refs/pull/12/head, fetched as git fetch <remote> <ref>. Refspec-hostile shapes are rejected up front: : would write a local ref dst, +/* force/glob, a leading - parses as a git option, ../leading-trailing / are invalid ref syntax, and whitespace/control bytes never appear in a ref name.
