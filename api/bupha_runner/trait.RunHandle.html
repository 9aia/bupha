Expand description

A running job — the local impl wraps Child; remote runners (SSH, hosted agents) impl this over their own handle so the worker’s wait/cancel logic stays unchanged.

fn failure_desc(&mut self) -> Option<String>

Failure cause for the status description — remote impls distinguish infra failures (“ci infra: sync failed”) from pipeline failures. Default None = plain “ci failed”.
